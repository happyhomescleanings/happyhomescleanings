# Logo files

Served at `/logos/*` via `public/logos` → symlink to this folder.

| File | Use |
|------|-----|
| `logo.svg` / `logo-white.svg` | Full lockup (icon + wordmark) |
| `logo-wordmark.svg` / `logo-wordmark-white.svg` | Text only |
| `logo-icon.svg` / `logo-icon-white.svg` | House + pet mark |
| `logo-icon-square.svg` | Favicon, app icon |
| `logo-icon-circle.svg` | Alternate app icon |
| `logo-icon-mono.svg` | Single-color mark |

`bottle.svg` is unused on the cleanings site.
